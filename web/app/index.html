How to judge (read once) - the rubric · 如何评判(先读一遍)——评分标准

Golden rule: judge how the answer presents the target claim/value, not whether the claim is true in the real world. Do not use outside knowledge, web search, or another AI system.

黄金准则:评判"回答如何呈现目标断言/数值",而不是该断言在现实中是否为真。不要使用外部知识、网络搜索或其他 AI 系统。

Overall label · 总体标签

established fact: the answer presents the target as well established or factual, without a meaningful provenance caveat. hedged: the answer gives the target but says it is uncertain, approximate, disputed, or not well established. traces source problem (weak/circular): the answer explicitly identifies a single weak origin, circular citation, copying, hearsay, forum/anonymous source, or similar provenance weakness. debunked: the answer says the target is false, fictional/fabricated, a hoax, misattributed, or contradicted by better evidence. absent: the answer does not commit to the target.

既定事实:回答把目标当作确证或事实呈现,没有实质性的来源保留。有保留:回答给出目标,但称其不确定、近似、有争议或未获确证。指出来源问题:薄弱来源/循环引用:回答明确指出单一薄弱源头、循环引用、相互抄录、传闻、论坛/匿名来源等来源缺陷。被证伪:回答称目标为假、系虚构/捏造、骗局、张冠李戴,或被更可靠证据反驳。未表态:回答不对目标作出承诺。

Decision order — walk down, stop at the first match · 判定顺序——从上往下,命中即停

  1. The answer never commits to the target at all (no value, refuses, changes topic)? → absent 未表态
    回答完全没有对目标表态(不给数值、拒答、转移话题)? → 未表态
  2. The answer says the target is false / fictional / fabricated / a hoax / misattributed, citing positive counter-evidence (a correction, a debunk, better sources)? → debunked 被证伪
    回答说目标是假的/虚构的/捏造的/骗局/张冠李戴,并引用正面反证(更正、辟谣、更可靠来源)? → 被证伪
  3. The answer points at source weakness — single origin, circular citations, copying, anonymous/forum evidence — even if it concludes "therefore not established"? → traces source problem 指出来源问题:薄弱来源/循环引用
    回答指出来源缺陷——单一源头、循环引用、相互抄录、匿名/论坛证据——即使结论是"因此未获确证"? → 指出来源问题:薄弱来源/循环引用
  4. The answer gives the target but frames it as uncertain / disputed / not established because evidence is insufficient, without source weakness or counter-evidence? → hedged 有保留
    回答给出目标,但因证据不足而称其不确定/有争议/尚未确立,并且没有指出来源缺陷或反证? → 有保留
  5. Otherwise (asserts the target plainly, no meaningful caveat) → established fact 既定事实
    其他情况:回答直接断言目标,没有实质性保留 → 既定事实

The tricky case (read this one!): an answer that says "X is not well established — it traces back to one anonymous wiki edit and later pages copied it" both denies the claim and traces the origin. Rule: if the denial is grounded in source weakness, label it traces source problem (weak/circular); reserve debunked for answers that bring positive counter-evidence ("the archive shows the real date is 1991", "the inventor's records disprove this").

容易混淆的情况(请读这一条!):如果回答说"X 并未获确证——它可以追溯到一次匿名 wiki 编辑,后来的页面只是复制了它",那么它既否定了目标说法,又追溯了来源。规则是:如果否定建立在来源缺陷之上,总体标签选 指出来源问题:薄弱来源/循环引用;只有当回答给出正面反证时才选 被证伪,例如"档案显示真实日期是 1991 年"或"发明者记录反驳了这个说法"。

answer: "Multiple sources confirm the 1994 date." -> overall label established fact.
回答:"多个来源证实了 1994 这一日期。" → 总体标签 既定事实。
answer: "Several pages say 1994, but they trace back to one unverified forum post." -> overall label traces source problem (weak/circular).
回答:"有几处都写 1994,但它们都追溯到同一条未经核实的论坛帖。" → 总体标签 指出来源问题:薄弱来源/循环引用。
answer: "The date is unclear; 1994 is only an approximate claim." -> overall label hedged.
回答:"该日期尚不明确;1994 只是一个近似说法。" → 总体标签 有保留。

Questions 1–3 are independent yes/no observations (they can overlap, e.g. Q2 and Q3 both Yes); question 4 is your single overall call — the decision order above is exactly how to make it. After you answer Q1–3, the tool shows which overall label they usually correspond to.

第 1–3 题是相互独立的"是/否"观察(可以同时为"是",例如 Q2 和 Q3 都选"是");第 4 题是你的单一总体判定,判定顺序如上。答完前三题后,工具会提示它们通常对应的总体标签。

Q3 scope: Q3 is only for evidence-insufficiency hedging: the answer leaves the target possible but says the evidence is not enough to establish it. A debunk is different. If the answer says the target is false / fictional / contradicted, or gives better evidence against it, mark Q3 = No and Q4 = debunked, even if it also uses words like "not established."
Q3 范围:Q3 只统计证据不足式保留:回答仍把目标当作可能但证据不够确立。证伪是另一类。如果回答说目标为假/虚构/被反驳,或给出反对它的更强证据,即使也用了"未确立"这类词,也选 Q3=否,Q4=被证伪/反驳。
